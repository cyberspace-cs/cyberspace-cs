## 2. 本轮新增 6 篇的详细判读（数字须准确引用）

### 2.1⚠️ Noise-corrected GRPO（arXiv:2510.18924）——**吃掉我们一半的"翻转"叙事**

| 项 | 他们的结论 |
|---|---|
| 记号 | ρ⁺ ≡ 我们的 FPR（真实错被判对），ρ⁻ ≡ 我们的 FNR |
| 核心假设 | **τ = 1 − ρ⁺ − ρ⁻ > 0** |
| **会不会翻转训练方向？** | **不会。** 噪声后surrogate = τ·Δ/σ̃，因τ>0，**期望方向与无噪声同向** |
| 破坏的是什么 | 更低的**固定点/平衡点**（原文：strictly lower fixed point），不是方向反转 |
| σ=0 全同组 | 只在介绍 Dr.GRPO 时提了一句"identical group rewards yield zero gradient"，**未系统分析** |
| 噪声率来源 | 合成实验**注入已知值**；真实 RM 实验从**平衡留出集估计**（GSM8K 上747/类，τ̂ 误差 ~0.108） |
| 实测噪声率 | GSM8K：`AceMath` ρ⁺=0.020 / ρ⁻=0.392；`Llama3.1-ORM` ρ⁺=0.216 / ρ⁻=0.324。APPS：`RM-Mistral-7B` **ρ⁺=0.53** / ρ⁻=0.233 |
| 增益 | math最高 +6.7pt，code +1.5pt |

> **⚠️ 这条必须改我们的叙事。** 我们 v4 §4.4"结论一"说"误报率为 0 时漏判升到100% 也不翻转"——
> **这篇论文从理论上证明了同一件事**（τ>0 时不翻转），且比我们严格。
> 我们的贡献不能是"我们发现不翻转"，只能是：
> **①我们指出 τ<0 这个反转区**（他们的核心假设把它排除在外）；
> **② τ = 1 − FPR − FNR 意味着 FPR 与 FNR 是耦合的预算，不是两个独立旋钮**——
> 社区把 FPR 当"保守一点没关系"的旋钮，但按 τ 算，FPR 直接吃掉信号保留量。
> **③ σ=0 退化区他们没系统分析**（见下）。

### 2.2 ⚠️ Delay/Plateau/Collapse（arXiv:2605.02909, COLM 2026）——**吃掉"误报导致崩溃"**

原文关键句：
> "systematic false positives can cause a wide range of behaviors from sub-optimal plateaus to performance collapse.
> Crucially, these outcomes are **not determined by the overall error rate but by the specific pattern of introduced errors**."

| 项 | 他们的结论 |
|---|---|
| 随机漏判 vs 系统性漏判 | **系统性漏判 ≈ 随机噪声**（都是"拖慢"） |
| 系统性**误报** | 从次优平台期到**崩溃**，范围极宽 |
| 决定因素 | **错误的模式（pattern）**，不是总体错误率 |
| 前提 | 原文：分析限定在**V\* 可算**的设定 |
| 我们的位置 | 我们的 **NMI(答案类别,判错) = 0.501~0.596** 就是"pattern"的量化，且我们在**V\* 不可算**的会计域 |

> 他们**只做定性分类**（plateau / collapse），**没有给闭式判据**。
> 我们有闭式阈值表（FPR=0.20 → FNR 阈值 0.800）。**这是真差异，但要说清是"定量 vs 定性"。**

### 2.3 ✅ Where the Verifier Fails（arXiv:2609.01354）——**最接近我们方法论的一篇**

> "generating **certified-equivalent** answer variants—rewrites that preserve mathematical meaning **by construction**, so that any rejection is a **provable false negative needing no human adjudication**"

**这与我们"参照可构造，不需标注"是同一个思想，且他们已在 math 域做出来了。**

| 项 | 他们 | 我们 |
|---|---|---|
| 免人工手段 | 变异测试生成**保义改写** | 注入舞弊算子生成**破坏集** |
| 保义/破坏的前提 | 改写必须**保持数学意义** | 注入必须**确定破坏某条约束**（DIC 认证） |
| 规模 | 307,420 verdicts，4 个 verifier | 7 verifier，3,200 oracle 自平 |
| 分层 | 按 **answer 形式类别** | 按**检测层/归因层**（原创） |
| 自陈 limitation | **"No training runs. We do not measure downstream RLVR effect"** | 我们做了解析后果，但也没真跑 RL |
| 难度维度 | ❌ | ✅ 我们的旋钮 |

> **他们的自陈 limitation 正是我们的机会**：他们明说没测下游 RL 后果。
> 而我们在 `2605.02909` 那篇的基础上已经有一套闭式后果模型。
> **"误差分类 → 闭式训练后果"的完整链条，目前没人做全。**

### 2.4 ⚠️ FinVerBench（arXiv:2605.29586）——**会计域被占，但占得很浅**

| 项 | 事实 |
|---|---|
| 数据 | SEC 10-K XBRL，**43 家 S&P 500**，真实财报 |
| 误差分类 | 四类：arithmetic / cross-statement linkage / year-over-year / magnitude |
| 规模 | **105-instance可观测子集**（43 clean + 62 注入），15 个模型跑 14 个完整 run |
| 头条数字 | 9/14 个 run 在干净报表上 **95–100% 误报** |
| 渲染敏感性 | 同一子集，取整变体后 recall 100% → **79.0%**（FPR 仍 0） |
| **它测的是什么** | **被测 LLM 判"报表是否一致"的误报**，不是"判分器的误差" |
| 自陈结论 | construct-validity 结论，**明确说"不是最终排行榜"** |

> **它没有审计 judge。** 它审计的是"LLM 能不能当审计员"。
> 我们审计的是"LLM 当判分器时错多少、错在哪个类、错的后果是什么"。
> ⚠️ **但它证明了一件事：会计域的"报表一致性验证"已经被占，而且做得比我们扎实（有真实 SEC 数据）。**
> ⇒ **我们的会计域不能再声称"域是空的"，只能说"这个域里判分器的误差没人测"。**

### 2.5 ⚠️ When the Judge is Wrong（SSRN 6482162）——**思路最像，但级别最低**

- **图验证构造 ground truth**（与我们的"可构造 oracle"撞名的思路）—— 454 题，10 类，5 种报表
- Claude Opus 4.6 四配置：strict 5.6% 分歧 / 7.1% 误接受；lenient 12.0%；**blind 40.4%**；**grounded 72.2% 一致但 31.7% 误接受**
- **缺陷**：**SSRN 工作论文，未同行评审**、0 引用、单模型、无难度维度、无 RL 后果

> 这篇验证了我们的核心假设（**judge 在结构化金融任务上误接受率很高**）
> 但它**没有可发表的方法学贡献**。我们的引用价值：**用一篇预印本支持"这个问题真实存在"**，
> 然后打它的缺口（单模型、无难度、无后果、级别低）。

### 2.6 AutoBenchmark —— 见 `24-AutoBenchmark借鉴.md`，此处只记一句

它用**零误差刻画的 LLM judge** 决定 benchmark 迭代生死 ⇒ **它就是一个待测 verifier。**

## 3. 逐条判定我们还剩什么

| 我们的候选贡献 | 判定 | 依据 |
|---|---|---|
| ①"verifier 误差能零标注测出" | 🟡 **被部分占** | `2609.01354` 已在 math 域用保义改写做到免人工；`SSRN` 用图验证做到 |
| ② **误差–难度曲线**（连续参数化） | ✅ **唯一干净的空白** | Table 1 第 6 列全表只有我们 |
| ③ 误报比漏判更致命 | 🔴 **已被占且更强** | `2605.02909`(COLM) 已实证"系统性误报⇒ 平台期到崩溃"，比我们的解析式更可信 |
| ④ 无梯度退化（σ=0） | ✅ **有真空间** | `2510.18924` 只在介绍 Dr.GRPO 时提了一句，**未系统分析**；这是我们实测最硬的（100% 退化组） |
| ⑤ 结构性不可见（判据集 ∩ 破坏集 = ∅ ⇒ FNR≡1） | ✅ **保持原创** | 无人做；且与 `2609.01354` 的"分类别计数"互补 |
| ⑥ 检测层/归因层分离 | ✅ **保持原创** | `2609.01354` 分的是 answer 形式，不是判定环节 |
| ⑦ 参照可**连续参数化** | ✅ **最强差异** | 别人都是固定数据集上测 |

### 🔴 必须承认的：我们的"翻转"叙事要降级

`2510.18924` 从理论上证明了 **τ>0 时不翻转**，比我们的蒙特卡洛严格。
我们不能再把"不翻转"当发现，只能把它当**已知结论的引用**，然后主张：

> **①τ = 1 − FPR − FNR 把 FPR/FNR 变成耦合预算：FPR 不是"保守一点"的旋钮，它直接吃掉信号保留量。**
> （社区默认可以调 FPR 而不管 FNR，这个直觉在 τ 记账下是错的）
>
> **② τ<0 是真正的反转区，而社区只测 τ>0。** 实测：
>
> | judge | FNR | FPR | **τ** | 判定 |
> |---|---|---|---|---|
> | deepseek-flash | 0.500 | 0.000 | **+0.500** | 同向，训练方向正确 |
> | deepseek-v4-pro | 0.380 | 0.800 | **−0.180** | **落在反转区** |
>
> pro 的 τ=−0.180 **正好跨过 τ=0 分界线**——这才是 pro 把训练方向带反的机制，
> 也是我们唯一能说"我们发现了新东西"的地方。
> **⚠️ 诚实边界**：取 CI 下界（FNR 0.291 / FPR 0.652）则 τ=+0.057，**仍在同向区**。
> ⇒ **A1 补样本的真正意义不是"收窄 CI"，而是"把 τ 的符号钉死"。**
> 补到 `n_clean=80` 时 τ=−0.016，**才第一次跨过 0**。这是 A1 必须做的量化理由。
>
> **③ σ=0 退化区无人系统分析。** 我们的 `equation_only` 是 100% 退化组、不报错、曲线正常。

## 4. 方向定稿

### 4.1 主命题（一句话，替换 v4 §3）

> **RLVR 的判分器质量是可测的，而且测出来之后会直接改变训练结论。
> 但现有工作只在 oracle 免费可得的域（math/code）测它，且只报聚合错误率。
> 我们给出可构造的参照 oracle + 连续难度参数化，从而回答一个别人回答不了的问题：
> 判分器的误差是**均匀存在**，还是**过了某个难度阈值才崩塌** —— 以及误报如何把训练方向带反。**

### 4.2 三个 RQ（终于写下来，替代 22/23 文档的欠账）

| RQ | 内容 | 对应实验 | 现状 |
|---|---|---|---|
| **RQ1** | 判分器的 (FNR, FPR) 能否在**零人工标注**下精确测出，且随难度连续变化 | 会计域 ≥4 档难度 × ≥6 模型 | 🔴 **未做（F6，Critical）** |
| **RQ2** | 误差是均匀的还是在阈值后崩塌；归因层与检测层是否分离 | 错误预算矩阵 + NMI 随难度 | 🟡 部分（单档已测） |
| **RQ3** | 给定 (FNR, FPR)，能否**闭式预测**训练失效形态，且哪一列决定方向反转 | 闭式阈值 + σ=0 退化 + verl 实跑 | 🟡 解析+MC 已做，**真跑 RL 未做** |

### 4.3 论文只留 3 条贡献（砍掉 F8 的 6 项）

1. **可构造参照 oracle** → verifier 审计不必限于 oracle 免费域（**方法**）
2. **误差–难度曲线 + 检测/归因分层 + 结构性不可见** → 失效有形状（**发现**）
3. **τ 记账 + σ=0 退化** → 误报如何吃掉信号保留量并让训练停摆（**后果**）

降级：难度旋钮降为方法的一个性质；DataFlow 落点与国家审计叙事进 Discussion。

| **B1** | verl 真跑（pro-judge vs flash-judge） | 把 RQ3 从解析推到实测 | 高 |

> **A0 是全部工作的瓶颈。** 在它跑出来之前，RQ1 只能说"一个点"，
> 而"一个点 vs 一条曲线"是我们全部差异的落脚点。**它不通，论文降级为 case study。**
